Tips for Effective Tab Management

Tab Order Matters

  • • Start with "Info" tab to introduce your service
  • • Follow with "Requirements" to set expectations
  • • End with "Quote" to encourage action

Icon Guidelines

  • • Use descriptive Lucide icons
  • • Common choices: info, list, calculator, package
  • • Keep icons consistent with your brand

Tab Types Explained

  • • Info: Displays service description and features
  • • Requirements: Shows requirement form fields
  • • Quote: Displays pricing and quote form

Best Practices

  • • Keep tab titles short and clear
  • • Only show BOM tab if service has materials
  • • Test tab order from client's perspective
