Tips for Effective Requirements

Field Naming

  • • Use descriptive field names (e.g., "project_area", "budget_range")
  • • Use lowercase with underscores for field names
  • • Avoid spaces and special characters in field names

Pricing Integration

  • • Check "Affects Price" for fields that change cost
  • • Set appropriate multipliers (1.5 = 50% increase)
  • • Use lower multipliers for smaller impacts

User Experience

  • • Keep labels clear and concise
  • • Use placeholder text for examples
  • • Add help text for complex fields

Field Order

  • • Start with basic information first
  • • Group related fields together
  • • End with optional or detailed information
